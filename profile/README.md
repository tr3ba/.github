## About Treba

Treba is a team marketplace project focused on modern web development,
cloud infrastructure, CI/CD and production deployment.

## Current stack

**Frontend:** Next.js · React · TypeScript  
**Backend:** ASP.NET Core · Entity Framework Core  
**Database:** PostgreSQL · Amazon RDS  
**DevOps:** Docker · GitHub Actions · Amazon ECR · EC2 · AWS Systems Manager  
**Operations:** CloudWatch · IAM · Secrets Manager · RDS Backups
